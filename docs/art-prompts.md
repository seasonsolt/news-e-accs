# 插画提示词（e/acc 蒸汽朋克风格）

用途：网站阅读页的背景动效、分类头图、日报报头、空状态。风格以 `tools/make-media.sh` 用到的那批插画为准
（羊皮纸上的古董工程版画、棕褐墨线交叉排线、黄铜和紫铜点缀）。

## 怎么画

1. 在 ChatGPT 里新开一个对话，**先发「统一风格」那一段**，再逐张发下面的提示词。同一个对话里画，风格最稳定。
2. 每张都要 **横版 3:2（1536×1024）**。ChatGPT 默认给方图的话，补一句"横版 3:2"。
3. 每张可以多画几次，挑最好的一张，**按表里的文件名保存**到 `~/Desktop/eacc-art/`（PNG 原图就行，压缩我来做）。
4. 画面里**不要出现文字、字母、数字和 logo**（AI 画的字是乱码，网站上的字由网页自己显示）。

## 统一风格（每个新对话先发这一段）

> From now on, every image you make in this chat follows one fixed style: an antique engineering engraving
> on aged parchment, like a page from a Victorian inventor's notebook. Fine sepia-brown ink linework with
> cross-hatching, technical-drawing details (faint construction lines, small measurement marks without
> numbers), selective brass and copper accents with a soft warm glow, muted palette of parchment, sepia,
> brass, copper and deep teal. Steampunk machinery, gears, pipes, valves, pressure gauges. Calm, detailed,
> wonder-inspiring. Generous empty parchment around the subject so text can sit on top. No text, no letters,
> no numbers, no logos, no watermark, no modern screens with UI. Landscape 3:2.

# 时代画卷（四维视角 /chronicle）

用途：`/chronicle` 观察窗里的版画，一个时代一张。**每个时代用它自己时代的画风**（时代 id 和画风名以 `industry/chronicle/eras.json` 为准）。
页面的黄铜外框是固定的"观察者仪器"，只有窗里的画随时代换风格。

## 怎么画

1. 每条提示词自成一体（画风 + 内容），**不发统一风格段**。为免画风串味，每画 4–5 张就新开一个对话。
2. 横版 3:2（1536×1024），下方三分之一保持安静，留给图注。
3. 不要文字、字母、数字、签名、logo、水印——手抄本、海报这类本来带字的画风尤其要注意。
4. 不用在世艺术家的名字，只用时代流派和媒介。
5. 保存为 `~/Desktop/eacc-art/epochs/<时代 id>.png`，再跑 `tools/make-art.sh`。
6. 再跑 `uv run tools/make-depth.py`，给新版画生成深度图 `<时代 id>-depth.webp`，观察窗的景深视差要用它（没有深度图的版画就是静态图）。模型是 Depth Anything V2 Small（Apache-2.0），在本机运行；Base 和 Large 是 CC-BY-NC，不能用。里程碑版画要传目录：`uv run tools/make-depth.py apps/web/public/media/art/moments`。
7. 为观察窗和场景大图生成 3840 像素宽的高清版。使用无水印的 PNG 原图，核对并更新素材清单后运行 `tools/upscale-chronicle.py`；具体模型、命令和来源记录见 `tools/art/chronicle-upscale-2026-10-27/README.md`。

每条提示词末尾都加上这句：

> Landscape 3:2 (1536×1024). Keep the lower third calmer so a caption can sit on it. No text, letters, numbers, signatures, logos or watermarks anywhere.

# 事件配图（四维视角 · 里程碑）

# 壁纸（4K）

所有生产壁纸带 `e-acc.ai` 水印：裁切后、颗粒前添加，使用 `assets/og-fonts/noto-sans-sc-700.ttf`，白色 55% 不透明、黑色 35% 阴影偏移 2px。桌面右下角字号 44px，距右边、下边各 64px；手机底部居中字号 56px，距底边 260px。预览从已带水印的桌面版生成。`WATERMARK=0` 仅用于自查；生产上传保持默认开启，服务器不添加水印。

运行 `tools/make-wallpaper.sh` 后，在 `/admin/wallpapers` 上传 `<name>-desktop.jpg`、`<name>-phone.jpg` 和 `<name>-preview.webp` 三个文件，填写北京上线日期及中英文标题。预览由桌面版经 `cwebp -q 72 -resize 1600 0` 生成；可以提前上传未来日期。

用途：订阅壁纸，每天一张，桌面版 3840×2160，手机版 2160×3840。ChatGPT 网页版出图一般是 1536×1024，所以在本机用 `tools/make-wallpaper.sh` 放大成 4K。

## 怎么画

1. 在 ChatGPT 里画 **横版 3:2（1536×1024）**，人工生成、人工保存。订阅版条款不允许用脚本自动操作 ChatGPT。
2. 桌面版会裁掉上下各约 8%，手机版只保留横向中间约 37% 宽的竖条。主体放在画面中部，左右两侧也要能单独成画。
3. 不要文字、字母、数字、logo 和水印。

## 放大

1. 第一次使用前，从 [Real-ESRGAN 发布页](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0) 下载 `realesrgan-ncnn-vulkan-20220424-macos.zip`，解压到不在仓库里的目录，例如 `~/Applications/realesrgan/`。
2. 运行：
   ```bash
   REALESRGAN=~/Applications/realesrgan/realesrgan-ncnn-vulkan tools/make-wallpaper.sh ~/Desktop/今天的图.png
   ```
   输出 `<文件名>-desktop.jpg` 和 `<文件名>-phone.jpg` 到 `~/Desktop/eacc-wallpaper/`。M1 Max 上一张约 30 秒。
3. 可调参数：`GRAIN`（颗粒强度，默认 4，0 为关闭）；`FOCUS_X`（手机版保留哪一段，0 最左，1 最右，默认 0.5）。

只用 `realesrgan-x4plus` 模型（BSD-3，可以商用）。Upscayl 里的 4x-UltraSharp 和 Remacri 是 CC BY-NC-SA，不能商用；其他模型没写许可证，也不要用。
