# 时间隧道 · 1800–1844

本地独立原型：沿时间轴飞行穿过里程碑的插画，在 1822 走进差分机工坊的三维场景。没有接入生产路由，也没有修改时间线数据。

## 运行

在仓库根目录运行：

```sh
python3 tools/prototypes/chronicle-tunnel/preview.py
```

打开 <http://127.0.0.1:8843/tools/prototypes/chronicle-tunnel/>，可加 `?t=1822` 直接停在某一年。服务从仓库根目录提供文件，隧道直接读取 `apps/web/public/media/art/moments/` 里网站现有的 `-1600.webp` 插画和 `-depth.webp` 深度图（`tools/make-depth.py` 生成，白 = 近），不另存副本。Three.js 复用 `difference-engine-1822/vendor/`，不依赖 CDN。

## 试玩

- 滚轮、拖动或 ←→：沿时间轴前后飞行，停手后落到最近的里程碑；年份随飞行连续变化。
- 移动鼠标：画面按深度分层视差。
- 停在 1822 时点「走进工坊」或按 Enter：画面淡入为同一视角的三维工坊，镜头随后离开原画视角；「回到时间线」原路返回。

## 实现

- 每幅插画是一块按深度图起伏的网格，排在 Z 轴上，间距随相隔年数增长。顶点沿视线朝停留点拉近，所以从停留点看插画与原图逐像素一致，移动时才分出前后层。
- 停留点按 `object-fit: cover` 取景。工坊的「原画视角」（`views.painting`）用同样的裁切规则换算视场角，所以交接时画面与三维场景对齐。
- 工坊以 `?embed` 在 iframe 里预载并暂停渲染，用 `postMessage`（同源校验）交接：`ready` → `enter` → `entered` → `exit`。交接期间隐藏工坊的界面，镜头落定后再显示。

## 原型边界

只覆盖 1800–1844 有插画的六个里程碑（1804、1843 没有单独插画）。深度落差大的边缘做了淡出，近景仍会有轻微拉伸。未做手机真机验收。
