# 加速史 · 精简布局原型

本地独立原型，用来比较 `/chronicle` 的另一种页面布局：首屏只放插画、时间轴和三个读数，其余内容收进同一个侧层。没有改动 `apps/web` 的线上代码，也没有修改时间线数据。

## 运行

先启动网站 API（`npm run dev:api`，默认端口 3001），然后运行：

```sh
python3 tools/prototypes/chronicle-focus/preview.py
```

打开 <http://127.0.0.1:8844/?t=1822>。`preview.py` 提供本目录的页面，`/media/*` 指向 `apps/web/public/media`，所以插画和字体沿用网站路径；`/api/site/chronicle` 转发给 API，可以用 `--api` 换成别的地址。

## 首屏

- 插画铺满观测舱，切换时淡入淡出。左下角依次是距今、时代、画风、年份、标题和一句说明。
- 三个读数是世界人口、一次能源功率、伦敦→纽约消息时间，拖动时间轴时实时变化，每个读数都和今天比较。三个读数分别对应人口、能源、信息三个维度，最直观地体现加速。
- 时间轴是对数刻度，按类别着色显示里程碑，当前时代高亮。点击或拖动定位时间（9 像素内吸附到里程碑），滚轮缩放，横向滚动平移，←→ 逐幅切换插画，地址里的 `?t=` 随之更新。

## 深度隧道与工坊

首屏的插画改由 `depth-stage.js` 绘制，做法来自 `../chronicle-tunnel/`：
- 时间轴上的每一幅画（时代开端和有插画的里程碑，即 ‹ › 的停靠点）按时间顺序排在 Z 轴上，间距相同。时间轴的位置决定镜头的位置：停在一幅画上就是这幅画的原图，拖到两幅画之间就在两幅之间飞行。
- 网站的 `-depth.webp` 深度图让画面按层视差，鼠标移动时分出前后。一次跳过很多幅时，镜头从目标前 6 幅开始飞。镜头附近只保留几幅插画的贴图。
- 在画面上滚动逐幅穿越，在时间轴上滚动仍是缩放。
- 停在 1822 差分机时出现「走进工坊」（或按 Enter），工坊原型以 `?embed` 在观测舱内的 iframe 里打开，和隧道原型用同样的交接消息。观测舱和 iframe 同样大小，所以原画视角能对齐。
- `?flat` 回到平面插画，方便对比；浏览器不支持 WebGL 时也用平面插画。

`preview.py` 把 `/difference-engine-1822/` 指向工坊原型目录，`three` 也从那里的 `vendor/` 加载；所有文件不缓存，改完刷新就能看到。三维模块和数据同时加载，首屏直接停在目标插画上，插画加载完才淡入，加载中的插画会挡住后面的插画。

## 侧层

观测舱右上角的「全部读数 / 此刻附近 / 时代画卷」打开同一个侧层，侧层有三个标签：

- **全部读数**：卡尔达肖夫指数和五项指标，每项指标附一条走势线。
- **此刻附近**：离当前最近的 8 个里程碑（点击跳转），以及此刻已有的能力和接下来会出现的能力。
- **时代画卷**：49 个时代的缩略图，点击跳到该时代的开端。

侧层打开时观测舱变窄但仍可操作，时间变化时侧层内容同步更新。Esc 或 × 关闭侧层，焦点回到打开它的按钮。

## 与线上页的差别

- 线上页首屏以下依次是五项读数、里程碑列表、能力、「此刻的本站」、时代画卷和浮动订阅条。原型只在首屏以下保留一行出处说明和一个静态订阅框。
- 「此刻的本站」没有放进原型。它依赖站内文章接口，适合另起一个入口。
- 格式化和坐标函数从 `packages/contracts/src/chronicle.ts` 和 `apps/web/app/features/chrono/format.ts` 复制到 `focus.js` 顶部。正式采用时应直接复用原模块，不要另留副本。

## 原型边界

只按桌面端设计，没做手机端布局；首屏一直在跑 WebGL，手机上的性能也没测。只有中文。侧层内容在页面里但默认隐藏，正式版要确认搜索引擎仍能读到里程碑列表。
