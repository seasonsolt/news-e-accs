SCENE STUDY / 001
让历史成为可以探索的空间。
1822 年，巴贝奇提出差分机。这一幕以现有插画为美术参考，用三维机架、数轮、传动齿轮和手柄搭建一间可探索的工坊。
演示计算 n²：从 A = 0、B = 1、C = 2 出发，每轮依次执行 A ← A + B、B ← B + C。寄存器、机械数轮和数表保持一致。齿轮与传动动画是原理示意，未复刻完整历史机构。
场景为艺术概念复原；1822 年对应差分机的提出，完整工坊和机器不代表当年已存在的实物。
