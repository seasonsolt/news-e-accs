# 原型验收记录

日期：2026-10-24，Asia/Taipei。范围：本地独立单场景，不代表生产发布或用户美术验收。

## 原型本身

- JavaScript 语法检查通过。
- 三项单元测试通过：完整 0–99 平方数表与十进制进位、复位不保留旧结果、行走范围及机器碰撞边界。
- 内置浏览器实际检查 1440×900、390×844、320×760 视口。320 宽度时控制栏在 x=14…306 内，无横向溢出。未做手机真机验收。
- 验证全景、走近与侧看预设镜头；拖动环视与 W 键行走；直接点击三维数轮和侧面的三维手柄；点击纸张标记聚焦数表。
- 单轮操作得到 A=1、B=3；后续得到 A=4、9、16。连续运转、暂停与复位可用。面板、三维数轮和三维纸张随计算更新。
- 手机点击「转动一轮」会展开原理面板，显示计算结果，也可再次收起。
- 模拟 `prefers-reduced-motion: reduce`，预设镜头直接抵达，计算以离散步骤完成。验收后已清除模拟与视口覆盖。
- 原画对照弹窗可打开，Escape 可关闭。
- 原型浏览器检查结束时 console warning/error 为空。静态几何合并、重复数轮实例化后，首次主画面的 draw calls 为 136；未把该数字当作帧率测试。
- 静态服务仅绑定本机 127.0.0.1:8842。没有线上部署、提交或付费资产生成。
