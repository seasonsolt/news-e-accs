# 手机专属壁纸与场景展示

范围：2026-10-21 网站已有的全部 140 套壁纸，包含已发布和排期内容。`manifest.json` 保留原 ID、日期、标题和文件名，作为替换前的映射。进度以实际文件为准。

- `originals/`：由原桌面作品重新构图的 9:16 手机专属插画，使用内置 ImageGen；每张保留完整提示词。
- `phone/`：用 `tools/make-phone-wallpaper.sh` 导出的 2160×3840 JPEG。原生生成尺寸约 941×1672，经 Real-ESRGAN 放大并加入站点水印，不声称原生 4K。
- `mockups/`：用户选择的逐张 AI 手机场景图，双手机分别演示锁屏和主屏；图中的界面、光线和透视为 AI 合成示意，细节可能与真实系统不同。下载文件不含手机外壳或系统界面。

制作标准：保留原题材与画风，为时钟留出相对安静的上部区域，重要主体尽量适应窄屏裁切。逐批目视检查构图、设备形状和屏幕内容；保存文件不代表已发布。

发布时沿用原壁纸 ID 与排期，保留桌面原图及付费下载记录；新的手机原图仍进入私有存储，不放到公开静态目录。公开展示使用低分辨率场景预览。
