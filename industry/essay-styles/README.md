# 长文文风

写作台（`/admin/essays`）每篇文章选一个文风。文风有两种来源：

- **后台上传**（常用）：在 `/admin/essays` 的“文风”卡片里选整个 skill 文件夹、它的 `.zip` / `.skill` 包，或单独一份 SKILL.md，传上去马上能选，不用发布。同名再传一次就替换旧版，之后的写作用新版；没有文章在用的上传文风可以删掉。只读包里的 `.md`、`.txt` 文字，脚本和其他文件不读也不执行；上限 60 个文件、30 万字。上传的文风存在数据库 `essay_styles` 表里，随数据库备份。
- **站点自带**：放在这个目录，随发布上线，名字不能被上传的占用。

每个文风一个文件夹，里面一份 `SKILL.md`：

```markdown
---
name: 文风的名字（小写字母、数字、连字符；自带的文风用文件夹名）
description: 一句话说明这个文风适合写什么
---

写作要求（语气、句式、用词、结构偏好、要避免的写法……）
```

文件夹里其他的 `.md`（包括子文件夹里的）作为参考材料一起读入，按路径排序。提纲、成稿、单节重写和中文版四步都把文风放进系统提示；每次模型产出记下文风的名字和内容指纹。

文风只管怎么写，事实规则（不编造事实、数字和引语，存疑处标 `[[check: …]]`）和格式由 `industry/prompts/essay-*.md` 管，文风里不必重复，也不能推翻。

`plain` 是先带上的中性文风。
