# 长文文风

写作台（`/admin/essays`）每篇文章选一个文风。每个文风一个文件夹，里面一份 `SKILL.md`：

```markdown
---
name: 文件夹名
description: 一句话说明这个文风适合写什么
---

写作要求（语气、句式、用词、结构偏好、要避免的写法……）
```

文件夹里其他的 `.md`（包括子文件夹里的）作为参考材料一起读入，按路径排序。提纲、成稿、单节重写和中文版四步都把文风放进系统提示；每次模型产出记下文风的名字和内容指纹。

文风只管怎么写，事实规则（不编造事实、数字和引语，存疑处标 `[[check: …]]`）和格式由 `industry/prompts/essay-*.md` 管，文风里不必重复，也不能推翻。

`plain` 是先带上的中性文风；使用者自己的文风放进来、随发布上线后即可在写作台里选。
