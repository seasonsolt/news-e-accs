# 每日 4K 壁纸

公开产品页：`/products/wallpaper`，中文 `/zh/products/wallpaper`。预览、图库、MCP 的 `wallpaper_today` 都公开匿名；只有原图使用订阅者专属 key。

## 每日操作

1. 在 ChatGPT 手动画图，保存原图。
2. `tools/make-wallpaper.sh SRC.png OUT_DIR`：生成桌面 JPEG（3840×2160）、手机 JPEG（2160×3840）、预览 WebP（宽 1600）。需要本机 Real-ESRGAN、ffmpeg、cwebp。默认在裁切后、颗粒前加入 e-acc.ai 水印，预览继承桌面水印；`WATERMARK=0` 仅供自查，生产保持开启。
3. 登录 `/admin/wallpapers`，填写北京上线日期、中英文标题，上传三个文件。可提前上传未来日期；到日后自动进入列表，today 选择不晚于今天的最新一张。

同一天重复上传覆盖内容，保留 ID 和已付款记录。仅能删除未来且没有付费下载的记录。预览保存在 `dataDir/uploads/wallpapers/`，包含在 uploads 备份范围内，带 `s-maxage` 由边缘缓存。配置了 `WALLPAPER_STORE_*` 时，4K 原图上传到私有的 S3 兼容存储桶（生产用 Cloudflare R2，下载流量不计费），下载验 key、扣积分后跳转到 5 分钟有效的签名链接；没配置时原图也在本机目录里。内容哈希文件名允许预览长期缓存；替换时保留旧文件，避免破坏已经缓存的预览 URL。

## 额度与安全

已确认且未退订的订阅者首次领取 100 积分，可兑换 10 天的壁纸。同一天的桌面版、手机版、重复下载只扣 10 积分；事务中的唯一下载记录保证并发只扣一次。积分不足 10 后不能下载新日期，已付款日期仍可下载，暂无充值。

key 只凭 newsletter token 领取：订阅确认页的按钮和"领取壁纸链接"邮件里都是 `#token=` 链接，打开时才轮换 key（旧 key 失效，积分不变）。邮件里不放 key，所以只知道邮箱的人请求链接，不会让别人正在用的 key 失效。邮箱领取走现有的来源限流、封禁、10 分钟冷却和每日发信上限；未订阅的地址改发订阅确认信。数据库只存 key 的 SHA-256，明文只在领取时返回给本人；页面把 key 存进浏览器后清掉 URL 片段，浏览器存储不可用时仍可在当前页面使用。

专属链接等于额度，不要分享。退订后所有 key 下载停止。下载（包括跳转）及个人额度响应为 `private, no-store`。签名链接 5 分钟后失效，所以转发出去的链接也很快作废。日志、代理、分析系统不要收集 key 查询参数；上线前确认边缘遵守缓存头并转发 `/products/*`。
