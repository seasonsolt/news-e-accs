# 加速史：从火堆到巨石

`/chronicle/walk`（中文 `/zh/chronicle/walk`，代码在 `web/walk/`）是一条可以从头走到尾的路：约一百万年前的火堆 → 黑夜里的岩画石檐 → 一万两千年前的第一把种子 → 村落 → 麦田 → 随时代升起的风车、电网、射电天线与算力机房 → 麦田中央的石头，全在同一片地形里，天色和年份读数随走过的距离变化。

页面在 `module.ts` 登记，`server.ts` 把它放进站点地图；入口在加速史观测舱的读数下方（「走进去」，`apps/web/app/routes/chronicle.tsx`）、《降临派宣言》末尾（`apps/web/app/routes/manifesto.tsx`）和“更多”的创作一栏（`apps/web/app/components/shell/nav.ts`），站点没有这个模块时各处入口都不显示。`/chronicle/workshops` 和原来各工坊的地址由 `module.ts` 的 `redirects` 301 到这里。页面自己画全部界面（路由 `handle` 的 `bare`），不带站点导航；首屏直接送出带环天体与麦田黑碑的封面，竖屏使用同幅作品的近裁图、入口准备提示和三章图记，点「开始行走」才下载 three.js、创建画布。加载栏依次显示场景下载、地形、麦田、地标和首帧光照，等待时可以取消。设备无法打开三维画面时可以重试，或沿原生锚点阅读图记。触碑后，镜头从田边望向暮色中的黑碑和人影，远处的风机声与近处的麦浪相叠。减少动态效果时直接切到静止远景。结尾有《降临派宣言》的〈小麦〉、今天的加速史、重玩和分享入口，左上角的返回在封面上也能点（行走中途返回会跳到加速史对应的年份）。页面报匿名的计数：开始、触碰巨石、第一次走过路上各处（`land.ts` 的 `MILESTONES`）、添柴等操作，以及离开时走到的最远处和大致时长，每次打开页面每项最多一次（`docs/analytics.md`，`#s300` 调试跳转不计入）；新的地名或操作要同时加进 `packages/backend/src/site/analytics.ts` 的 `WALK_*`，否则服务器会丢掉。

开发运行见仓库 `docs/deploy.md`；`npm run dev:web` 连接本地 API。

- `orbit.ts` 把封面里的天体固定在天空的同一方位。入场时，树梢、岩棚和火塘前的人挡在它前面。沿路天亮，环带逐渐隐去，触碑后又出现在麦田的暮色里。点击开始时天体贴图和地形并行准备，两者都就绪才显示第一帧。
- `land.ts` 不依赖 three.js：路的走向（`roadX`）、地面高度（`ground`）、水域阻挡与木桥通行（`keepDry`、`bridgeLift`）、各处的位置常量、年份读数（`yearReading`）和旁白（`LINES`）。测试测这一层及路由发现与统计契约。
- 场景模型由代码生成，岩石与地表结合实拍扫描材质。`shapes.ts` 是基础形体（带层理和断面的石头、枝干、团块、车制轮廓、碎石堆），产出的几何带位置、法线、颜色和一个 `surface` 标记（0 普通、1 石、2 树皮与木、3 土与茅草、4 叶团、5 皮肤、6 布、7 毛发）；`surface.ts` 的 `createMatte` 是所有静态景物共用的一个材质，按这个标记为石块映射实拍岩面，为树皮、布和皮肤生成对应的表面细节，所以景物仍可按路段合并绘制。
- `trees.ts` 生成树和灌木：递归长出的枝干、带镂空叶形的叶片、透光和随风摆动。`grass.ts` 按覆盖度分布草丛和矮茬，远处变稀并融进地面颜色。`groundcover.ts` 是地面着色细节（沙粒、干裂的洼地、车辙、火塘的灰圈）和散落的枯枝、落叶、小石子。
- `world.ts` 分阶段让出主线程构建地形、天空、草和麦田并处理行走：一张逐点着色的地形网格、一个天空着色器（`sky.ts` 按视线绘制银河、地平线雾霭和远山，天色按 `HOURS` 表渐变）、实例化的草丛、由 `wheat.ts` 按地块实例化的麦秆、叶片与麦穗。近处可见籽粒、麦芒与茎节，远处切换为简化穗形。播种后麦浪沿路向前长出。后期有环境光遮蔽（地址加 `?ao=0` 关闭）和泛光，天空同时作为环境光（`?env=0` 关闭）；桌面端有跟随行人的日月阴影和近距离开启的火堆点光阴影，手机上不开阴影。
- `camp.ts` 是火堆周围与夜路中段的赭石手印岩画石檐：火塘、木柴、柴堆、草棚、石器台、围火的四个人、岩棚巨石、火光边缘会随添柴退去的眼睛，以及半途石壁上的红土手印与奔兽岩画。人物和羊的形体在 `people.ts`（一组关节位置就是一个姿势；身体各段沿关节蒙皮成截面渐变的管，衣服、头发和帽子是盖在上面的壳，按 `dress` 分火堆旁的兽皮、村落的裹裙和田间的束腰长衣；脸是颅骨上一整张按五官加密的面，鼻、唇、眼睑由它起伏而成，眼球是单独的球，头发、眉毛和胡子是一缕缕细带；每人的脸型、五官、年纪和神情都不同，`child` 画孩子的头身比例）。`village.ts` 是清晨的村落：屋子、粮仓、羊圈、泥灶、晾架和干活的人。`fields.ts` 是麦田沿途：水塘、水渠与桔槔（农夫随横杆俯仰拉水），木桥、收割的人与麦垛，立石与日影杆，以及随脚步从麦田里升起的风车、电线杆、高压电塔、风力发电机、射电望远镜天线与低矮算力机房（`land.ts` 的 `CLEARINGS` 记着这些地方不种麦）。`verge.ts` 画路面和路边的野花，`clouds.ts` 画云。`props.ts` 摆放散石、伞形树、灌木、播种处的先民与种子篮和巨石（`monolith.ts` 构成一块厚、宽、高按 1∶4∶9 建模的哑黑长方体，底边嵌入麦田），把以上各部分接在一起，并把景物占的圆交给行走做碰撞。打开页面不调用模型。
- `relief.ts` 在开始漫步后并行载入本地两张扫描材质。红、绿、蓝通道分别存储相对明度、高度和粗糙度。土路与两侧地面沿同一坐标采样，营地岩面和路边散石共享石材。材质抵达前可以开始行走，来源和作者见 `NOTICE`。
- `sound.ts` 的声音全部用 Web Audio 现场合成，没有音频文件：火、石檐回响、虫鸣、风、麦浪、鸟、水、石磨、风车、电线低鸣、算力机房气流与谐波、脚步和手触石面的轻响，按走到的位置和天色混合。点「开始行走」后才发声，页面上的「声音」按钮可以关掉，选择记在浏览器里。
- 行走：W A S D 或方向键、拖动环视、滚轮推进、Shift 加快；触屏用「按住前行」；「自动前行」沿路走，拖动能边走边看，切到后台会暂停自动前行。互动只有三处（添柴、播种、触碰巨石），用 E 或屏幕上的按钮。地址后加 `#s300` 可直接从路上 300 的位置开始，方便调试。
- 文案的中文写在 `land.ts`、`world.ts` 和 `page.tsx` 里，英文在 `web/walk/messages.ts`。三章图记在 `Guide.tsx`，译文在 `guide-messages.ts`。测试覆盖双语服务端页面、无脚本阅读和场景加载失败后的重试。
