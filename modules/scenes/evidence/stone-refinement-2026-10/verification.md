# 石器工坊精细化验证

2026-10-25，分支 `codex/chronicle-more-workshops`，基于 `claude/chronicle-prototypes`。本轮只重做当前石器工坊的三维素材、地形、光照和断面；2026、用火、农业保持上一轮实现。预览为 `http://127.0.0.1:54860/zh/chronicle/stone-tools`。没有提交、推送、上传 R2 或发布生产站。

## 画面

- [近景，第一次剥片](stone-close.png)：扫描石核、锤石与工作岩台，石片来自石核的实际裁切网格，保留外皮的原 UV；新断面使用单独材质。
- [侧看，三次剥片完成](stone-side.png)：断面沿交线封口；修正径向排序连接不规则边缘造成尖刺的问题。凹轮廓另有几何测试，避免只验证方块。
- [全景，复位后](stone-wide.png)：扫描岩石、实例化草木、独立砂砾地面、高度起伏与环境雾；修正远处地形在侧面留下天空裂缝的问题。
- [390×844 手机近景](stone-mobile.png)：完成实际加载、走近和第一次打制；没有横向溢出或场景错误提示。

截图均来自最终生产构建的内置浏览器原始截图，没有后期处理。桌面图为 1440×900，手机图为 390×844。桌面图使用桌面视口，但几何在首次进入时按实际窄屏加载，因此图中植被数量采用较低档；没有用桌面截图宣称低端手机性能达标。

扫描资产来自 Poly Haven CC0，逐项授权、下载地址和校验值记录在 `assets/stone-tools/sources.json`。保留扫描几何，将纹理打包进自包含 GLB；植被单独的 Alpha 贴图合入颜色通道，修正黑底叶片和成排模型变体的布局。砂砾有独立颜色、法线、粗糙度和高度图，HDR 只提供环境光，场景另有太阳光与接触阴影。

9 个本地素材文件合计 **20,741,555 字节，约 19.8 MiB**。它们在 `.data/scene-sources/stone-tools/` 与 `apps/web/public/media/scenes/stone-tools/` 中，均被 Git 忽略；源记录和内容哈希 manifest 进 Git。首次加载体积仍较大，尚未做真实低端手机帧率或弱网测试。这是可交互美术与原理示意，裁切是预设几何演示，没有模拟真实断裂力学，也没有宣称照片级质量或用户已认可画面。

## 保留的交互

在最终构建、普通动效下实际验证：

- 走近、全景、侧看及拖动环视；键盘移动仍由原共享相机控制。
- 在锤石上方、热点按钮范围之外点击三维网格，剥片次数从 0 变成 1；热点按钮也能推进。
- 逐步到 3 次剥片，界面为 04/04，主操作停止；复位后为 01/04、完整石核与 0 次剥片。
- 自动演示推进到 04/04 后停止，按钮恢复“自动演示”。
- 从 `/zh/chronicle?t=-3300000` 的桌面时间线预加载完成后进入真实 iframe，打制至 02/04，再返回时间线；入口恢复“走进石器工坊”，键盘焦点回到主画卷。
- 查看原画、关闭原画后仍可继续打制。
- 390×844 重新载入后可走近和打制；不把只缩放一个已加载桌面页面当作手机加载验证。

浏览器读取到新模型、地面与 HDR 的 9 个同源内容哈希地址，场景运行时不从 Poly Haven 下载，也没有模型请求。
