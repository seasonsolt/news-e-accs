# 十个时代工坊小游戏验证记录

2026-10-26。读者主入口为本地正式构建预览：<http://127.0.0.1:54860/zh/chronicle/workshops>。

## 实现范围

新增十个可失败、调整、重试和复位的独立三维小游戏，沿用主站界面、行走、环视、走近、实体拾取与时间线交接。阶段按钮不能直接跳关；主操作只检验或执行当前选择，只有明确启动「自动演示」才示范正确操作。既有智能体、石器、用火、农业与差分机场景保留各自玩法。

| 工坊 | 玩家选择与完成条件 |
|---|---|
| 文字 | 选择货物与数量，按委托正确登记三笔账目。 |
| 铁器 | 加炭、鼓风，在可锻状态有效锤击两次，再冷却成形。 |
| 印刷 | 排字、校对、上墨和压印；每份重新上墨，完成三张书页。 |
| 观星 | 对照星图调整方向与焦距，记录月面、木星和金星三次观察。 |
| 蒸汽 | 配合汽阀与负载，使压力和转速同时达到目标；每个工况连续测试两次，共三组。 |
| 电光 | 选择目标接点、合上开关并测试，依次点亮三支灯；短接触发保护断开。 |
| 飞行试验 | 按三张配平卡移动重心、调整升降舵，通过三段试飞检验。 |
| 逻辑电路 | 设置输入 A、B 和预测输出，逐行正确检验 AND 四行真值表。 |
| 轨道对接 | 平移与偏航同时对正后推进，通过三段接近检查点并软对接。 |
| 网络分片 | 按序选择三片消息，为每片选择可用路径，完整重组消息。 |

历史入口与机构资料链接见 `web/games/{craft,science,modern}.ts` 的场景目录和本模块 README。观星装置采用 1610 年，避免把望远镜放到 1543 年；蒸汽入口为 1769 年，说明中区分入口年代与跨时期机械概念。所有装置和刻度均为教育概念示意，不是精确历史复原、真实设备操作指南、实测遥测或真实外部任务。

## 本轮修正

- 异步加载结束、同步建场景之前检查退出状态，避免离开页面后继续构建已销毁的场景。
- 动态装置与显隐变化更新阴影；静态合并保留动态对象、拾取对象及投影属性。
- 复位不再被误判为新试飞或成功发送；失败发送不启动成功包动画，数据包不穿过当前断路。
- 手动实体操作和主操作暂停自动示范，避免示范继续替玩家改变选择。
- 蒸汽最后一个工况完成后保留稳定采样 `2 / 2`；逻辑结果使用 `0/1`，四行检验完成才结关。
- 里程碑入口与测试 fixture 使用真实时代标识，保持图库、时间线和场景目录一致。
